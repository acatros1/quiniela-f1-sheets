# 🏁 Quiniela / Fantasy F1 en Google Sheets

Sistema automatizado para ligas de Fantasy F1 en Google Sheets conectado con la API de Jolpica/Ergast.

## ⚙️ Configuración
1. Clona este proyecto o copia el script en el editor de Apps Script de tu Google Sheet.
2. Configura en **Configuración del proyecto > Propiedades de la secuencia de comandos** la clave `MAPEO_JUGADORES` con el JSON correspondiente (ver `config.example.json`).
3. Ejecuta la inicialización desde el menú superior en Google Sheets.
